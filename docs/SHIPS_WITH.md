# Ships with

The public release has one workflow: **enter a profile, paste a job ad, prepare up to three CV and cover letter
pairs per month.** It ships only the files that workflow needs. Every file is listed here with its purpose, its
origin and its redistribution rights. `tests/test_release_scope.py` fails when a tracked file is missing from this
list, so nothing joins the release without an entry.

Rules for adding a file:
- The workflow above must need it.
- Its origin is known, and we may redistribute it (written by this project, or a license that allows it).
- No real job ads, employer pages, real applications or personal data, and no third-party templates or prompts with
  unclear rights, in examples or tests. Use invented people, companies and ads.

|---|---|---|---|

| `LICENSE` | license text | this project | MIT |

| `start.sh` | starts the app (Linux, macOS) | this project | MIT |
| `start.bat` | starts the app (Windows) | this project | MIT |
